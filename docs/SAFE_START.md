# Безопасный первый запуск

## Программная демонстрация

1. Оставьте все `BERETS_REAL_*` равными `0`.
2. Создайте уникальные секреты в локальном `berets.env`.
3. Установите зависимости и запустите тесты.
4. Запустите `python3 pr3.py`.
5. Проверьте авторизацию, страницы, журнал и цифровой двойник.

Программный режим не является подтверждением готовности приводов.

## Подготовка физического стенда

1. Снимите силовое питание.
2. Проверьте полярность и отсутствие короткого замыкания.
3. Проверьте независимую аппаратную аварийную остановку.
4. Освободите рабочую область и снимите груз.
5. Проверьте датчики без запуска двигателей.
6. Проверьте один сервопривод изолированной утилитой.
7. Проверьте конвейер без объектов.
8. Проверьте направление рельсы, оба концевика и поиск исходного положения на малой скорости.
9. Только после этого включайте общий аппаратный шлюз.

Не копируйте калибровку, маршруты и настройки тока с другого стенда без измерения.

## Сеть

Штатный интерфейс предназначен для доверенной локальной сети. Не настраивайте проброс порта 5000 на маршрутизаторе. Для удалённого доступа требуется отдельный VPN или защищённый обратный прокси с HTTPS, ограничением доступа и журналированием.
