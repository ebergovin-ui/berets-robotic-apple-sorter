# Участие в разработке

Обсуждения ошибок и предложений ведутся через GitHub Issues. Изменения исходного кода предлагаются отдельными pull request.

## Требования к изменению

1. Опишите назначение и границы изменения.
2. Не добавляйте секреты, журналы, сетевые адреса и данные пользователей.
3. Не отключайте аварийные проверки, программные пределы и контроль концевиков.
4. Сохраняйте одного владельца UART и GPIO.
5. Добавляйте или обновляйте автоматические тесты.
6. Указывайте отдельно результаты программной проверки и физического испытания.
7. Не заявляйте аппаратное подтверждение без воспроизводимого теста на реальном стенде.

## Локальная проверка

```bash
cd software/flask_app
python3 -m pytest -q
python3 -m compileall -q .
```

Изменение, способное вызвать движение, сначала проверяется в программном режиме, затем на одном узле без нагрузки и только после этого в составе общего цикла.
